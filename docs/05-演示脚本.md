# CheckBIM Agent — 3 分钟演示脚本

录制建议：桌面浏览器全屏；离线模式（`.env` 中 `CHECKBIM_OFFLINE=1`）。

## 开场（约 20s）

> 这是 CheckBIM Agent：BIM 工程师在交付前，用对话做几何碰撞和属性完整性自查。
> 本地运行，支持上传 IFC 或选样例；检查结论必须来自工具调用，不能编造。

展示：标题栏 / 左侧工作区 / 右侧对话。

## 路径 A — IFC 已知碰撞（推荐，约 90s）

1. 左侧样例列表点 **载入** → `demo-collision.ifc`
2. 状态应变为「已载入」；对话区解锁
3. 输入：**帮我查碰撞** → 发送
4. 口播结果：
   - 出现 ≥1 对墙-墙碰撞（外墙 A × 内隔墙 B）
   - 碰撞计数 ≥ 1
   - 提示「工具调用 N 次」；planner 为 `rules`（离线）
5. （可选）输入：**属性完整吗** → 应无缺失（两墙均有 Name / FireRating）

人工对照说明见 `test_samples/demo/README.md`。

## 路径 B — JSON 金标兜底（约 60s）

若 ifcopenshell 环境异常：

1. 载入 `collision_positive.json` →「帮我查碰撞」→ 应有碰撞对
2. 再载入 `collision_negative.json`（或上传同文件）→「帮我查碰撞」→ 空列表
3. 载入 `attrs_missing.json` →「查属性」→ 列出缺失项

## 收尾（约 30s）

> Agent 侧：离线用关键词规划；有 API Key 时走受控 ReAct，最多 5 步白名单工具。
> 护栏：没跑工具就不能说检查通过。
> 代码与提示词在 GitHub：`app/`、`prompts/`、`docs/`。

## 录制检查清单

- [ ] `uvicorn` 已启动，页面无「载入样例失败」
- [ ] 至少完整跑通路径 A 或 B
- [ ] 镜头能看清结果数字与 tool 提示
- [ ] 未在无工具情况下口头承诺「全部通过」

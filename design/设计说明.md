# CheckBIM Agent 落地页 — 设计说明

> 版本：v0.1 · 2026-08-24  
> 依据：[02-PRD.md](../docs/02-PRD.md) + UI 澄清对话（Q1–Q5）

---

## 用户

- **谁看**：BIM / 建筑工程师（产品最终用户）
- **何时来**：模型交付前自查，需要快速载入模型并开始检查

---

## 目标

- 用户进入页面后**立刻开始检查**：上传 IFC 或选择内置样例
- 传达**冷静、专业的工程工具**气质，像日常会打开的专业软件入口
- 为后续 Agent 工作台建立可信的第一印象（非营销页、非「AI 炫技页」）

---

## 主要按钮 / 行动点

| 优先级 | 行动 | 文案（三方案统一） |
|--------|------|-------------------|
| 主 CTA | 上传 IFC 并开始检查 | **上传 IFC 模型** |
| 次 CTA | 选择内置样例 | **选择样例模型** |
| 辅助 | 了解两项能力（非主按钮） | 碰撞检测 · 属性完整性 |

---

## 内容层级（自上而下）

1. **顶栏**：产品名 CheckBIM Agent + 一句极短副标题（交付前碰撞与属性检查）
2. **首屏重心 — 模型入口区**（最大视觉块）
   - 上传区（拖拽/点击）
   - 或：样例列表（小型 IFC / JSON 演示样例）
   - 双入口同级可达，不藏深
3. **能力标签**（次要）：碰撞检测 / 属性完整性 — 小标签或侧边说明，不抢入口
4. **可选窄条**（Should，非首屏重心）：检查结果示意（碰撞对数、缺失属性条数），增强「检查后长什么样」
5. **页脚**：版本 / 本地处理说明（一行即可）

**不出现**：大段营销文案、机器人插画、AI 霓虹装饰。

---

## 风格关键词

- 工程专业软件感
- 冷静、克制、工具向
- 深色或中性工业色（三方案在明暗上分化）
- 信息密度适中偏高（工程师习惯）
- 桌面专用布局（宽屏，不专门优化手机）

---

## 限制

| 类型 | 要求 |
|------|------|
| 范围 | 仅落地页；不做登录、工作台、结果页完整原型 |
| 设备 | **仅桌面**（≥1280px 设计基准） |
| 交互 | 按钮不必真工作；静态可查看即可 |
| 文案 | 真实简洁中文；核心文案三方案一致 |
| 默认避开 | 紫色渐变、发光、大面积玻璃卡片 |
| **额外避开（用户确认 C）** | 消费级营销风（大插画、口号堆叠）；过度 AI 感（机器人、霓虹、粒子、Powered by AI） |

## 三方案探索方向（确认后执行）

| 方案 | 名称 | 差异轴 |
|------|------|--------|
| 1 | **深色 CAD 工作台** | 深灰底 + 细线框 + 左入口右状态；类似传统 CAD 启动/文件对话框 |
| 2 | **浅色规范审查台** | 浅灰白 + 强网格/表格感 + 居中宽入口；类似审查清单软件 |
| 3 | **中性工业面板** | 蓝灰工业色 + 分区面板 + 紧凑工具条；类似 Navisworks / 协同平台入口 |

三方案共用：相同标题、副标题、双 CTA 文案、两项能力说明。
